# Bright Futures Recruitment: website

A static site (plain HTML, CSS and JS) generated by a small Python script, with a Decap CMS vacancy manager at `/admin/` so the client can add, edit and remove jobs and testimonials herself. Built by Sightwise, October 2026.

## Folder layout
| Path | What it is |
|---|---|
| `content/jobs/*.json` | One file per vacancy. **The client edits these through /admin/.** |
| `content/testimonials/*.json` | One file per testimonial (also editable in /admin/) |
| `_build/build.py` | The generator. Header, footer, job page, blog post templates and the `SITE` contact details |
| `_build/pages/*.html` | Page bodies (front-matter comment sets title, description, nav, share image, `faq: yes` for FAQ schema) |
| `_build/posts/*.html` | Blog posts |
| `_build/data/categories.json` | The 10 role categories (ids must match the CMS select in `admin/config.yml`) |
| `assets/` | CSS, JS, logo, photos (copied into dist/) |
| `admin/` | Decap CMS: `index.html`, `config.yml` (fields), `preview.js` (editor preview styled like the site) |
| `_redirects` | 301s from every old GoDaddy URL to the new pages |
| `netlify.toml` | Netlify build: `python _build/build.py`, publish `dist` |
| `dist/` | Build output. Generated, git-ignored, never edit |
| `docs/vacancy-manager-guide.md` | Plain-English guide to send the client |

## Build and preview locally
```
py _build/build.py
py serve_nocache.py
```
Then open http://localhost:5180 (Claude Code launch entry: "brightfutures"). Bump `ASSET_V` in build.py after CSS or JS edits.

To test the CMS locally, run `npx decap-server` in this folder, then open http://localhost:5180/admin/ and click Login (no password locally). Saves write straight to `content/`, then rebuild.

## Go-live checklist (the CMS needs Git-based deploys, not a drag-and-drop zip)
1. Put this folder in a **GitHub repo** (private is fine), branch `main`.
2. In **Netlify**, add a new site from that repo. netlify.toml sets the build command and publish folder.
3. **Site configuration → Identity → Enable Identity.** Set registration to **Invite only**. Under Services, **enable Git Gateway**.
4. **Identity → Invite users** → the client's email. She clicks the link, sets a password, and lands in /admin/.
5. **Forms:** turn on email notifications for all 5 forms (cv-registration, job-application, school-enquiry, contact, testimonial) to info@brightfuturesrecruitment.co.uk. CV uploads arrive as attachments in the Netlify dashboard.
6. **Domain:** in Netlify add brightfuturesrecruitment.com (plus www), then at **GoDaddy → DNS** change only the website records (A/ALIAS for @ and CNAME for www) to what Netlify shows. **Don't touch the MX/email records.** The domain stays registered at GoDaddy. Cancel the GoDaddy Website Builder plan once the new site is live.
7. Submit `https://brightfuturesrecruitment.com/sitemap.xml` in Google Search Console.

## Notes
- Vacancies with a **Date posted** get Google for Jobs (JobPosting) structured data. A **Closing date** adds validThrough, hides the job at the next build, and main.js marks it closed in visitors' browsers in between builds.
- The privacy page is a draft and says so on the page. The client must approve it before launch.
- Photos are from Unsplash (free licence). The logo is the client's own, cut out and never redrawn. Fonts are Lexend and Atkinson Hyperlegible Next.
